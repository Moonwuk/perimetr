# VPS 0.5.0 — проверка 5 октября 2026

Сборка для первого внешнего теста. Игровые HTTP-маршруты и движок общие с Cloudflare; на VPS меняются окружение, файловая SQLite и раздача статики. WebSocket в эту версию не добавлен: клиенты по-прежнему опрашивают состояние каждые 2 секунды, пока вкладка видна.

## Проверено локально

- 94 автоматических теста, включая 8 новых тестов VPS: миграции и откат, постоянная SQLite WAL, атомарные batch, ограничения запросов, поддельные IP-заголовки, безопасные пути и symlink, лимиты реальных HTTP-запросов.
- TypeScript и ESLint без ошибок; сборка интерфейса и самостоятельного Node.js bundle.
- `pnpm vps:test`: два независимых HTTP-клиента, приватная комната и открытый поиск, готовность обоих игроков, допустимые/недопустимые действия, скрытые данные, одновременная атака с одной ревизией (200 + 409, однократная оплата), переподключение, дежурство, сдача, взаимный реванш, финансовое завершение, закрытие комнаты хозяином.
- Перезапуск процесса в середине матча и после его завершения: состояние, авторизация мест и метрики сохраняются; закрытая комната не восстанавливается.
- Резервные копии: committed WAL попадает в отдельный переносимый SQLite-файл, целостность и права 600 проверены, ротация работает; восстановление и возврат через safety-снимок прошли. Проверены закрытая генерация ключа, отказ от перезаписи `.env` и валидация настроек.
- Точный Android CORS: preflight, ошибки и игровые запросы; чужие origin и доступ Android к выгрузке владельца запрещены.
- Два изолированных Chromium-контекста 390×844 и 320×568: открытый поиск, две готовности, touch-перетаскивание карты с одной оплатой, получение действия соперником, перезапуск Node + перезагрузка обоих браузеров + восстановление мест, закрытие комнаты у обоих игроков.
- Реальная загрузка JSON в браузере владельца: серверные и клиентские события присутствуют; коды комнат, ключи мест, имена и скрытые карты/расстановки отсутствуют. Ключ владельца не сохраняется после перезагрузки. Ошибок JavaScript в этом сценарии нет.

Команды для повторения:

```sh
pnpm test
pnpm lint
pnpm exec tsc --noEmit --incremental false
pnpm vps:build
pnpm vps:test
```

Для проверки распакованного архива используйте `VPS_SERVER_BUNDLE=/absolute/path/to/server.mjs pnpm vps:test` из репозитория. Процесс запускается непосредственно из архива; рядом с ним должны находиться `public/` и `drizzle/`.

## Что остаётся проверить на арендованном сервере

Docker Engine в среде проверки отсутствует: образ и Compose ещё не запускались здесь. Файлы Compose и shell проверяются отдельно; это не заменяет старт контейнеров на VPS. Выпуск настоящего TLS-сертификата, DNS, firewall, автозапуск после перезагрузки VPS и соединение двух телефонов через интернет требуют выбранного VPS и домена.

Число одновременных комнат и пропускная способность самого дешёвого VPS не измерены. Локальные функциональные проверки не доказывают увеличение нагрузки в 10 раз. Один экземпляр приложения использует одну SQLite; горизонтально размножать его этой конфигурацией нельзя.

Cloudflare D1 и локальная SQLite — разные хранилища. Этот комплект не переносит старые комнаты и не перенаправляет существующий Cloudflare-сайт. Для общего матча игроки должны открыть один сервер; Android нужно пересобрать с его HTTPS origin. Текущий подписанный Android-кандидат с пустым origin остаётся офлайн.
