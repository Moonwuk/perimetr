# Проверка установленного APK

Статус этих сценариев на физическом телефоне: **не выполнены**. Их нельзя засчитывать по сборке APK или снимку веб-интерфейса.

1. Установить подписанный APK на Android 8+ с обновлённым Android System WebView (Chromium 111+). Проверить холодный запуск и отсутствие белого экрана.
2. Включить авиарежим, начать матч против бота, расставить сеть и сделать несколько ходов. Правила и все карты должны открываться без сети.
3. Свернуть приложение и вернуться. Затем принудительно остановить через настройки Android, запустить и выбрать «Продолжить локальный матч». Деньги, карты и ход должны восстановиться.
4. Начать игру вдвоём на одном устройстве. На передаче хода должен быть закрывающий экран; после перезапуска чужая расстановка не должна открываться до подтверждения передачи.
5. Проверить кнопку «Назад»: сначала закрывается верхний диалог/карта, затем предлагается выход в меню. В меню закрытие приложения требует подтверждения. Выход не должен удалять сохранение.
6. Сменить ориентацию, открыть клавиатуру, проверить телефон с жестами и с тремя системными кнопками. Кнопки действий и все 25 клеток должны быть доступны.
7. Завершить матч. Проверить итоговый отчёт, повторный матч и сохранение результата. Сетевой режим должен явно показывать, что сервер ещё не запущен.
8. Без RuStore нажать «Обновления»: понятное сообщение, игра продолжает работать.
9. После загрузки тестовой версии в RuStore установить её из магазина, войти в RuStore и завершить три матча. Проверить, что форма отзыва не прерывает активный матч, её закрытие возвращает игру. Повторного запроса в течение семи дней быть не должно.
10. Загрузить тестовое обновление с большим versionCode и той же подписью. Проверить скачивание, отказ, повторную попытку, установку и сохранность локального матча.

## Снимки для карточки

Снять три вертикальных кадра из установленного APK: главный экран; расстановка инфраструктуры; идущий матч с картами. Подойдёт устройство/эмулятор с портретным экраном 1080×1920. Не выдавать браузерные превью за снимки Android.

Через Android Platform Tools:

```sh
adb install -r perimeter-0.4.1-release.apk
adb shell am start -n ru.moongametechnology.perimeter/.MainActivity
adb exec-out screencap -p > 01-menu.png
```

Остальные два кадра снять после перехода на соответствующие экраны. По документации RuStore: минимум три кадра, PNG/JPG, до 3 МБ на кадр для телефона, максимум 2160×3840. Перед загрузкой убедиться, что в кадре нет личных уведомлений.
