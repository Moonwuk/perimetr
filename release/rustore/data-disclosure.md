# Данные и разрешения версии 0.4.1

Это техническая заготовка для заполнения консоли, а не подтверждение соответствия всем юридическим требованиям. Перед публикацией владелец завершает политику и сверяет актуальные категории консоли.

| Что | Обработка в этой сборке |
| --- | --- |
| Расстановка, карты, деньги, результат локального матча | Только WebView localStorage в закрытом хранилище приложения; удаляются очисткой данных приложения |
| Счётчик завершённых матчей и дата запроса отзыва | SharedPreferences; нужны для ограничения частоты запросов |
| Аккаунт, email, телефон | Игра не запрашивает; авторизация в RuStore относится к отдельному приложению магазина |
| Камера, микрофон, контакты, файлы, геопозиция | Доступ не запрашивается |
| Реальные платежи, реклама, рекламный идентификатор | Не реализованы; рекламных/платёжных SDK нет |
| Запросы обновлений и отзывов | Через RuStore SDK; пакет, версия, подпись и данные выполнения запросов обрабатываются сервисами RuStore |
| Аналитические/диагностические события SDK | В транзитивных зависимостях присутствуют ru.rustore.sdk:analytics и metrics; это не собственная игровая аналитика, но учитывать её в декларации необходимо |

Сетевые комнаты в Android-сборке отключены. Игра не отправляет имя компании, расстановку или историю локального матча на игровой сервер. При включении сетевой игры потребуется обновить эту декларацию: название компании, токен места, состояния матчей и серверные журналы будут иметь другую обработку.

Из итогового AndroidManifest:

- INTERNET — сетевые запросы сервисов RuStore.
- ACCESS_NETWORK_STATE — состояние подключения.
- RECEIVE_BOOT_COMPLETED — добавлено транзитивными библиотеками RuStore; не является доступом к личным файлам.
- DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION — внутреннее разрешение приложения с уровнем signature, не запрос личных данных.

Опасных runtime-разрешений, AD_ID и REQUEST_INSTALL_PACKAGES в объединённом манифесте нет. Пакет самого RuStore указан в queries для взаимодействия SDK. Обновление устанавливается средствами RuStore.

В консоли не выбирать автоматически «данные не собираются»: декларация относится и к сторонним SDK. Сверить диагностические события, сведения о работе приложения и идентификаторы устройства/SDK с текущим описанием RuStore SDK и результатом тестового сетевого наблюдения. Такой тест на реальном устройстве ещё не выполнен; полный состав передаваемых SDK полей не подтверждён.

Резервное копирование приложения отключено. Для локальных данных срок хранения — до замены сохранения/очистки данных приложения; для технических данных RuStore — по политике сервиса. Владелец должен указать действительный канал обращений и полные реквизиты ответственного в публичной политике.
