# КОНТУР 0.4.1 — комплект RuStore

Срез: 4 октября 2026. Подготовлен установочный APK с release-подписью и исходники. Публикация в кабинете RuStore не выполнялась. Первый Android-релиз поддерживает бота и игру вдвоём на одном устройстве. Сетевой режим в APK закрыт до запуска общедоступного сервера.

## Что загрузить

1. В RuStore Console создать карточку «КОНТУР — кибердуэль». Проверить свободное имя пакета `ru.moongametechnology.perimeter`.
2. Загрузить `perimeter-0.4.1-release.apk`. Он уже подписан отдельным ключом игры. Для первого релиза проще использовать APK. AAB приложен как дополнительный формат; сначала настроить соответствующий ключ подписи в консоли.
3. Скопировать название, краткое и полное описание, «Что нового?» из `store-listing.json`.
4. Категория: «Игры / Стратегии» или ближайшая доступная в консоли. До пяти предлагаемых тегов есть в JSON; выбирать из реально доступных значений консоли.
5. Добавить `icon-512.png`. Фон непрозрачный, 512×512, PNG.
6. Добавить минимум три скриншота запущенного APK на Android: меню, расстановка, матч. Папка `previews` содержит только браузерные превью интерфейса, если они включены в комплект; перед отправкой заменить их снимками установленного приложения. Инструкция: `device-test.md`.
7. Заполнить возрастную анкету по содержанию игры. В ней нет денежных ставок, реальных покупок, чата, пользовательских публикаций, крови и натуралистического насилия. Окончательную маркировку выбрать в анкете RuStore, не угадывать её по жанру.
8. Заполнить контакт разработчика и публичную ссылку на политику конфиденциальности. В комплекте есть заготовка `privacy-draft.html`, требующая данных владельца; она ещё не опубликована.
9. Сверить «Безопасность данных» с `data-disclosure.md`. Нельзя выбирать «приложение ничего не передаёт» только потому, что основная игра офлайн: в сборке есть SDK RuStore.
10. Сначала пройти сценарии `device-test.md`, затем отправить версию на модерацию из кабинета владельца.

## Что нужно от владельца

- Email поддержки или другой доступный канал, который принимает консоль. Не использовать закрытый GitHub-репозиторий или закрытый сайт как канал поддержки.
- Имя/наименование ответственного за обработку данных и контакт для политики конфиденциальности. При необходимости владелец уточняет применимые правовые основания и сроки хранения.
- Доступ к кабинету RuStore и заполненная возрастная анкета.
- Проверка APK на настоящем Android-телефоне, включая сворачивание, возврат, смену ориентации и отсутствие интернета.
- Публикация заполненной политики по общедоступному HTTPS-адресу.
- Для онлайн-релиза: общедоступный сервер, соответствующая конфигурация клиента и отдельный тест двух устройств. Приватный сайт ChatGPT для массового релиза не подходит.

## SDK и поведение

Подключены `ru.rustore.sdk:review:10.5.1` и `ru.rustore.sdk:appupdate:10.5.1` из официального репозитория RuStore. Используются реальные Java API SDK. Покупки за реальные деньги, реклама и push-уведомления не реализованы, поэтому их SDK не подключены.

Проверка обновления запускается кнопкой в меню. Используется FLEXIBLE-обновление; установка предлагается вне активного матча. При отсутствии магазина/связи игра остаётся доступной. Запрос отзыва возможен после третьего завершённого матча, не чаще одного раза в семь дней. Оценка не даёт игровых наград и не зависит от победы или поражения. На устройстве без подходящего RuStore ошибка отзыва не прерывает игру.

Полноценная проверка диалогов магазина требует доступной в RuStore версии с этим packageName и той же подписью. Автоматическая сборка не является подтверждением прохождения модерации.

## Подпись

`perimeter-signing-private.zip` хранить отдельно от исходников. В нём приватный ключ и пароли. Не добавлять его в GitHub, карточку приложения или публичный архив. Следующие версии подписывать тем же ключом, увеличивая `versionCode`. Новый случайный ключ вместо старого нарушит совместимость обновлений.
