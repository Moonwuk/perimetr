# Проверка Android-кандидата 0.5.0

**Проверка упаковки выполнена; сценарии на устройствах ниже ещё не выполнены.** Подписанные APK/AAB 0.5.0 / 500 собраны, подписи/выравнивание/манифест проверены; `lintRelease`: 0 ошибок, 4 предупреждения. Подробности и хеши — в README. Адреса сервера и политики пусты: это офлайн-кандидат. После их настройки нужна пересборка. Браузерные автотесты и сборка не заменяют проверку установленного приложения и магазина; эмулятор и физический телефон для этого кандидата не использовались.

## Установка и офлайн

1. Проверить package `ru.moongametechnology.perimeter`, versionName `0.5.0`, versionCode `500` (или согласованное большее), подпись и SHA-256 APK. Установить на физический Android 8+ с актуальным System WebView. Холодный запуск без белого экрана и ошибок.
2. Если была установлена 0.4.1 с release-подписью, обновить через `adb install -r` без удаления данных. Проверить сохранение локального матча. При несовпадении сертификата остановиться, не обходить проблему удалением пользовательских данных.
3. В авиарежиме сыграть против бота и начать дуэль на одном устройстве. Карты, изображения, обучение и правила доступны. У сетевого режима понятное сообщение об отсутствии связи, без зависания остальных функций.
4. Свернуть, вернуть, принудительно остановить и снова запустить приложение. Локальные деньги, карты и ход восстанавливаются. В дуэли на одном устройстве чужая рука/расстановка закрыта экраном передачи хода.

## Мобильное управление

5. Короткое нажатие выбирает карту без автоматического открытия описания. Карта разыгрывается через цель и действие. Отдельная кнопка показывает детали; длинные правила по умолчанию свёрнуты.
6. Удержать карту и перенести на разрешённую цель. Подсветка совпадает с целью; после отпускания ровно один ход и одно списание. Бросок мимо, на недопустимую клетку, отмена касания, второй палец, сворачивание и поворот не тратят ресурсы.
7. До удержания обычный жест прокручивает руку. Карты без цели разыгрываются только в обозначенной зоне своей сети. Нехватка денег, отсутствие действий и чужой ход не позволяют сыграть карту.
8. Проверить небольшой экран, портрет/альбом, жестовую навигацию и три системные кнопки. Все 25 клеток и кнопка окончания хода доступны, нет горизонтального выхода страницы. Клавиатура не закрывает ввод/подтверждение комнаты.
9. «Назад» закрывает верхний диалог/выделение, затем запрашивает выход в меню; сохранение не теряется. Публичная политика открывается из приложения по правильному HTTPS URL.

## Два устройства и веб

10. После настройки и пересборки проверить точный публичный сервер: `/api/health`, постоянную SQLite и миграции на VPS (либо D1 при альтернативном Cloudflare размещении). Веб-игра и API используют один origin, тот же указан в APK. Прогнать два установленных APK, затем Android против веб-версии этого же сервера. Устройства должны быть в разных сетях, в том числе мобильной сети целевой аудитории.
11. Создать приватную комнату: автоматический поиск второго игрока её не находит; вход по коду работает. Создать публичную: поиск присоединяет ровно одного соперника. Пустой поиск сообщает, что свободных комнат нет.
12. Один игрок нажимает «Готов»: ожидание остаётся понятным. Второй расставляет сеть и нажимает «Готов»: матч начинается у обоих с одинаковым первым игроком. Чужие скрытые карты/расстановка не появляются.
13. Сделать несколько обычных ходов и бросков карты. Результат и кредиты совпадают на обоих устройствах; быстрые повторные нажатия не дублируют ход. Потеря сети/повторная отправка не даёт повторного списания.
14. Свернуть один APK, сменить Wi-Fi на мобильную сеть, вернуться. Показывается переподключение; место восстанавливается без второй учётной записи. Выход в меню позволяет вернуться в ту же комнату.
15. Кнопка закрытия есть у создателя. Отмена подтверждения оставляет комнату. Подтверждение закрывает её для обоих; старый код более не открывает матч. Новая игра после закрытия работает, прежнее офлайн-сохранение остаётся.
16. Завершить матч победой, сдачей и отдельно закрытием комнаты. Проверить соответствующий результат, повторный матч и восстановление UI у обеих сторон.

## Серверная статистика

17. Убедиться, что только сетевые матчи создают строки аналитики. Проверить запись подтверждённой карты, фактической цены, результата и отдельного события броска. Бросок мимо не должен считаться успешным серверным действием.
18. Владелец открывает веб-игру с `/?reports=1`. Без ключа и с неверным ключом экспорт закрыт; с `METRICS_EXPORT_TOKEN` скачивается JSON. В нём нет имён, открытых кодов комнат, токенов, рук и расстановок; усечение явно обозначено. Не включать секрет владельца в APK или скриншоты.
19. Сверить серверную плановую очистку (почасовой таймер VPS либо cron Cloudflare), срок 30 дней, удаление истёкших комнат, настройки журналов/резервных копий провайдера. Закрытие комнаты удаляет её состояние, статистика следует отдельному сроку. Зафиксировать порядок хранения скачанных отчётов.

## RuStore и выпуск

20. На устройстве без RuStore и без сети кнопка обновлений сообщает об ошибке без нарушения игры. После установки версии через RuStore проверить Review SDK после достаточного числа законченных матчей: не поверх активного матча, без наград и повторного навязчивого запроса.
21. Проверить Update SDK с доступной в RuStore новой версией, большим versionCode и той же подписью: скачивание, отмена, повтор, предложение установки вне матча, сохранность прогресса после обновления. Успешный `assembleRelease` не подтверждает этот пункт.
22. По реальным запросам и merged manifest сверить декларацию данных, SDK, разрешения и публичную политику. Заполнить владельца, контакт, URL политики, возрастную анкету и маркировки. Убедиться, что описание обещает только работающие в APK функции.

## Скриншоты установленной версии

Снять минимум три актуальных кадра: меню, расстановка, матч с рукой карт. Можно добавить сетевое ожидание. PNG/JPG, телефон до 3 МБ на кадр, максимум 2160×3840. Портретный формат 1080×1920 удобен; не публиковать личные уведомления, секреты и тестовые сообщения.

```sh
adb install -r /absolute/path/to/verified/perimeter-0.5.0-release.apk
adb shell am start -n ru.moongametechnology.perimeter/.MainActivity
adb exec-out screencap -p > 01-menu.png
```

Путь в команде — пример; текущий проверенный APK указан в README. Для сетевых скриншотов использовать пересборку с проверенным сервером. Остальные кадры снять после перехода на нужные экраны.
