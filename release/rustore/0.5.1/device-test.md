# Проверка установленного КОНТУР 0.5.1

Статус всех сценариев: **не выполнено на устройстве**. Сборка и автотесты не подтверждают эти сценарии.

| Проверка | Ожидаемый результат |
| --- | --- |
| Установка / обновление с 0.4.1 или 0.5.0 | Та же release-подпись; package `ru.moongametechnology.perimeter`, версия 0.5.1 / 501; сохранение остаётся |
| Авиарежим | Бот и дуэль на одном устройстве работают, рисунки и правила доступны |
| Сворачивание / завершение процесса / возврат | Матч сохраняется; чужая рука скрыта экраном передачи хода |
| Одинаковые карты | Стопка ×N; после розыгрыша количество уменьшается ровно на одну |
| Перетаскивание | Карта поднимается без предварительного выбора; бросок на допустимую цель списывает ресурсы один раз |
| Отмена жеста / бросок мимо / второй палец | Хода и списания нет; обычная прокрутка руки доступна |
| Узкий экран / поворот / клавиатура / «Назад» | Поле и важные кнопки доступны; диалог закрывается до выхода в меню |
| Два APK в разных сетях | Приватная комната по коду; поиск открытой комнаты; старт только после готовности обоих |
| Android ↔ веб | Одинаковые результаты действий; закрытые карты и расстановки соперника не раскрываются |
| Пауза / переподключение / сдача / реванш | Пауза требует согласия; возвращение восстанавливает место; результат одинаков у обоих |
| Политика / контакт | Открываются реальные публичные адреса; соответствуют карточке |
| RuStore отсутствует / нет сети | Проверка обновления не прерывает игру |
| Review / Update | Проверить с версией, доступной через RuStore: отзыв вне матча, обновление прежним сертификатом |
| Данные и скриншоты | Декларация сверена с итоговым манифестом/SDK; сняты меню, расстановка и матч актуального APK |

Снимки телефона: PNG/JPG, до 3 МБ каждый, максимум 2160×3840; минимум три. Не использовать старые превью, уведомления и секреты комнаты.

```sh
adb install -r /absolute/path/perimetr-0.5.1-candidate.apk
adb shell am start -n ru.moongametechnology.perimeter/.MainActivity
adb exec-out screencap -p > 01-menu.png
```

Для сетевых сценариев нужен новый APK после настройки сервера. После теста записать модель телефона, Android, WebView, сеть, хеш APK, дату и найденные проблемы. Подробные сценарии метрик/SDK сохранены в [предыдущем плане](../0.5.0/device-test.md).
