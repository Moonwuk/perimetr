# Perimetr — КОНТУР, корпоративная кибердуэль

Карточная игра MoonGameTechnology: компании развивают скрытую сеть 5×5, защищают серверы и мешают доходу соперника. Три категории карт — атака, защита и экономика. Побеждает компания, первой накопившая 3000 кредитов после полного раунда; партия ограничена 12 раундами.

Репозиторий: `Moonwuk/perimetr`. Название игрового прототипа — «КОНТУР»; окончательный бренд остаётся открытым.

## Что готово

- Мобильный интерфейс: соперник сверху, своя компания снизу, поле и карты помещаются на узком экране.
- Бот, дуэль на одном устройстве и веб-PvP по коду комнаты.
- Типовые контрмеры против DDoS, фишинга и саботажа, развитие экономики и бесплатные базовые действия.
- Сервер проверяет авторизацию места, ревизию, стоимость и допустимость ходов. Скрытые карты и сеть соперника не отправляются клиенту.
- Переподключение, взаимный реванш, отчёт партии, ограничения запросов и очистка просроченных комнат.
- Самостоятельная веб-сборка для Cloudflare Workers + D1.
- Android 8.0+, подписанные APK/AAB 0.4.1, RuStore Review/Update SDK и комплект подготовки публикации.

Cloudflare ещё не развёрнут в аккаунте владельца. APK 0.4.1 работает с ботом и локальным PvP; для онлайн-режима в Android потребуется отдельное обновление после появления публичного сервера. Публикация в RuStore и проверка на физических телефонах ещё не выполнены.

## Запустить веб-игру локально

Нужны Node 24 и pnpm 11.25.0.

```sh
pnpm install --frozen-lockfile
pnpm cf:dev
```

Команда соберёт интерфейс, применит миграции к локальной D1 и запустит Worker. Адрес покажет Wrangler; для двух участников откройте два независимых браузера или профиля.

## Проверки

```sh
pnpm test
pnpm exec tsc --noEmit --incremental false
pnpm cf:check
pnpm cf:test
```

При подготовке Cloudflare-пакета прошли 42 автотеста, TypeScript, сборка и dry-run Worker, HTTP-тест реального локального Workers/D1 и две независимые браузерные сессии. Подписанный Android 0.4.1 прошёл Gradle build, проверку подписи и lint без ошибок. Подробные границы этих проверок указаны в соответствующих отчётах; перенос в GitHub не является новой публикацией или проверкой на физическом устройстве.
