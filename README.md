# Perimetr — КОНТУР, корпоративная кибердуэль

Карточная игра MoonGameTechnology: компании развивают скрытую сеть 5×5, защищают серверы и мешают доходу соперника. Три категории карт — атака, защита и экономика. Побеждает компания, первой накопившая 3000 кредитов после полного раунда; партия ограничена 12 раундами.

Репозиторий: `Moonwuk/perimetr`. Название игрового прототипа — «КОНТУР»; окончательный бренд остаётся открытым.

## Что готово

- Мобильный интерфейс: соперник сверху, своя компания снизу, поле и карты помещаются на узком экране.
- Бот, дуэль на одном устройстве и веб-PvP по коду или через поиск свободной открытой комнаты.
- Типовые контрмеры, постоянное секретное дежурство всей сети, развитие экономики и бесплатные базовые действия.
- Разделённые фишинг и подмена платежа; внутренние серверы требуют предварительного доступа для перегрузки.
- Полные описания карт, причины недоступности, явный выбор поля и сохранение локального матча в браузере.
- Сервер проверяет авторизацию места, ревизию, стоимость и допустимость ходов. Скрытые карты и сеть соперника не отправляются клиенту.
- Переподключение, взаимный реванш, отчёт партии, закрытие комнаты её создателем, ограничения запросов и очистка просроченных комнат.
- Самостоятельная веб-сборка для Cloudflare Workers + D1.
- Общие метрики сетевых матчей в D1 и защищённая выгрузка JSON для разбора тестов.
- Android 8.0+, подписанные APK/AAB 0.4.1, RuStore Review/Update SDK и комплект подготовки публикации.

Веб-версия публикуется в аккаунте владельца на Cloudflare. Изменения этого репозитория попадают на сайт после слияния и успешного деплоя. Готовые APK/AAB 0.4.1 остаются предыдущей автономной версией; исходники 0.5.0 требуют новой подписанной сборки. Онлайн в Android по-прежнему требует адреса сервера и отдельной настройки. Публикация в RuStore и проверка этой версии на физических телефонах не выполнялись.

## Запустить веб-игру локально

Нужны Node 24 и pnpm 11.25.0.

```sh
pnpm install --frozen-lockfile
pnpm cf:dev
```

Команда соберёт интерфейс, применит миграции к локальной D1 и запустит Worker. Адрес покажет Wrangler; для двух участников откройте два независимых браузера или профиля.

### Открытые комнаты

При создании комнаты хозяин выбирает доступ: по коду или открытый поиск. По умолчанию комнаты закрыты для поиска; существующие комнаты после миграции тоже остаются доступными только по коду. Поиск сразу подключает ко второму месту одной свободной открытой комнаты, если её хозяин был на связи в последнюю минуту. Отдельного списка комнат и раскрытия расстановок нет. Оба игрока по-прежнему подтверждают расстановку перед стартом.

«Закрыть комнату» доступно её создателю и завершает доступ для обоих игроков. Выход в меню сам по себе комнату не удаляет. Повторные запросы входа после обрыва связи восстанавливают прежнее место по сохранённому ключу. Для этого обновления необходима миграция `0002_bent_garia.sql`; `pnpm cf:deploy` применяет миграции перед публикацией Worker.

### Метрики тестирования

Сетевые матчи автоматически пишут события в общую Cloudflare D1: карты и расходы, ход партии, победитель, длительность, закрытие комнаты и ошибки игровых запросов. Жесты перетаскивания учитываются отдельно. Бот и игра на одном устройстве в этот сбор не входят. Нужна миграция `0003_warm_revanche.sql`, которая также применяется через `pnpm cf:deploy`.

Для выгрузки добавьте Worker Secret `METRICS_EXPORT_TOKEN`, откройте игру с `/?reports=1`, введите ключ и скачайте JSON. [Настройка и состав отчёта](docs/METRICS.md). Сбор работает без ключа экспорта; данные хранятся 30 дней.
