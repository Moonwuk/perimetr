# Проверка КОНТУРА 0.5

4 октября 2026. Исходная версия: `0e78baa9ef7a59766adeb1309c441a83c6199634` (main после выравнивания лобби). Ниже результаты локальной проверки изменений 0.5, а не проверка опубликованного сервера.

## Правила и сборки

- 53 автотеста движка, API комнат и локальных сохранений: пройдены. Проверяются цены/AP и атомарность отказов, разведка и скрытые поля, контрмеры, разделение фишинга/платежа, доступ к внутренним сервисам, постоянное дежурство, миграция 0.4, законность действий бота, завершение по деньгам и реванш.
- TypeScript (`pnpm exec tsc --noEmit --incremental false`): ошибок нет.
- ESLint (`pnpm lint`): ошибок и предупреждений нет. Сгенерированные веб-бандлы и локальные Android/Worker-артефакты исключены из анализа исходников.
- Vite: автономная веб-сборка создана.
- `pnpm android:web`: общая игровая часть для Android создана. Это не сборка и не подпись нового APK.
- `wrangler deploy --dry-run --config cloudflare/wrangler.json`: Worker и привязки собраны без публикации.
- 1000 партий базы 0.4 и 1000 партий 0.5 на одинаковых семенах и с переменой мест: все завершились. После исправления ошибки бота при выборе уже выигрышного завершения повторены 1000 партий 0.5; итоговые счётчики не изменились. [Данные и ограничения методики](../docs/BALANCE.md).

## Реальный локальный Worker и D1

`pnpm cf:test` поднимает настоящий runtime Workers, применяет миграции к отдельной временной D1 и использует два независимых HTTP-клиента. Проверены:

- статические ресурсы, CSP, health, JSON 404 и отсутствие кэширования API;
- создание и вход, повтор потерянного запроса создания/входа без второго места, немедленное присутствие обоих участников;
- отказ чужому ключу и стороннему Origin, ограничение запросов и scheduled handler;
- недопустимая расстановка и действие вне очереди без изменения ревизии;
- обе расстановки, скрытые карты/сеть/тип дежурства и отсутствие чужого ключа в ответе;
- конкурентная атака с одной успешной записью и одним 409, восстановление авторитетного состояния;
- сохранение дежурства после возвращения собственного хода;
- сдача, запрет действий в завершённом матче, взаимный реванш с переменой первого игрока;
- полная вторая партия до финансового результата после 10 раундов, без тестового обхода правил.

Подтверждение расстановки теперь допускает один автоматический повтор на клиенте при 409: только для того же матча, пока своё место ещё не готово и сервер вернул более свежую ревизию. Повторяется та же расстановка. Платные игровые действия автоматически не повторяются.

## Интерфейс

Проверены браузерные viewport 320×568, 390×844 и 1280×900, дополнительно альбомная ориентация 844×390. Использовался Chromium headless, а не физический телефон.

- Лобби, расстановка, оба поля, карточные панели и действия без карты доступны без горизонтального переполнения.
- На низком экране карта открывается полностью в прокручиваемой панели с доступными кнопками. Состояние «нужна разведка/доступ/деньги» объясняется текстом.
- Памятка хода, переключение полей, бесплатная замена и подтверждение конца хода работают.
- Строительство списывает 240, оставляет 2 действия и увеличивает доход с 280 до 380. Скан открывает пять клеток и тратит одно действие. Замена карты сохраняет деньги и действия.
- Перезагрузка и продолжение восстанавливают локальную партию. Новая локальная партия запрашивает подтверждение замены незаконченного сохранения.
- Передача телефона и возобновление локального PvP скрывают сеть, карты и приватные сообщения; сообщение о заменённой карте не остаётся у следующего игрока.
- В проверенных сценариях ошибок JavaScript не было.

## Два независимых браузера и восстановление

В двух мобильных браузерных контекстах (390×844 и 412×915) проверены создание комнаты, вход по приглашению, обе расстановки, разведка и передача хода. Подтверждения расстановок намеренно попали на устаревшие ревизии: оба ответа 409 автоматически восстановились до 200 без второго нажатия.

Исходный длинный сценарий остановился на неверном ожидании теста при переключении хода. Поэтому восстановление проверено отдельно, с валидной комнатой, подготовленной через публичный API: браузеры вернули правильные места, перезагрузка гостя сохранила 270 кредитов, действия и дежурство, нажатие конца хода начислило доход один раз, обе кнопки реванша вернули игроков в расстановку с новым первым игроком. Завершение для этой изолированной проверки было подготовлено API-командой сдачи. Ошибок JavaScript не было. Это две целевые проверки, а не одна непрерывная партия целиком через интерфейс.

## Границы проверки

Не проверены удалённая D1 владельца, реальные задержки мобильной сети, фоновые ограничения Android и игра двух людей на физических устройствах. Симуляции не доказывают человеческий баланс: у чрезмерно защитной стратегии всё ещё слабая экономика, есть сигнал преимущества первого места.

Новый подписанный APK/AAB 0.5.0 не создавался. В репозитории сохраняются прежние подписанные сборки 0.4.1; исходникам следующей Android-сборки назначены версия 0.5.0 и versionCode 500.

После деплоя оба игрока должны перезагрузить страницу: уже открытый клиент 0.4 не знает новый вид карты. Для честного теста новых правил рекомендуется новый матч. GitHub Actions `Game checks` проверяет PR и `main` без публикации; Cloudflare и Android release workflow остаются отдельными ручными операциями.
